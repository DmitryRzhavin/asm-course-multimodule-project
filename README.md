Вариант **2-2-3**

### Заданные функции

```math
f_1(x)=3\left(\frac{0.5}{x+1}+1\right)\\
f_2(x)=2.5x-9.5\\
f_3(x)=\frac{5}{x}, \quad x>0
```


### Метод решения уравнений

Метод хорд (секущих).

### Метод численного интегрирования

Формула Симпсона.

---

## Структура проекта

### functions.asm

Ассемблерная реализация функций:

* f1(x)
* f2(x)
* f3(x)

Соглашение вызова: cdecl.

### functions.c

Вспомогательные функции:

* f12(x) = f1(x) − f2(x)
* f13(x) = f1(x) − f3(x)
* get_function()

### root.c

Функция

```c
double root(afunc *f,
            afunc *g,
            double a,
            double b,
            double eps);
```

Вычисляет точку пересечения двух функций методом хорд.

### integral.c

Функция

```c
double integral(afunc *f,
                double a,
                double b,
                double eps);
```

Вычисляет определённый интеграл по формуле Симпсона.

### main.c

Основная программа.

Поддерживает вычисление площади фигуры и тестирование функций root и integral.

```bash

```

```bash

```

Пример:

```text

```

---

### Тестирование root

Формат:

```bash
./integral -R F1:F2:A:B:EPS:R
```

где

* F1, F2 — номера функций;
* A, B — границы интервала;
* EPS — требуемая точность;
* R — ожидаемый результат.

Пример:

```bash
./integral -R 1:2:4:6:0.000001:5.09838671
```

Вывод:

```text
5.0983867100
0.0000000000
0.0000000000
```

где:

1. найденный корень;
2. абсолютная ошибка;
3. относительная ошибка.

---

### Тестирование integral

Формат:

```bash
./integral -I F:A:B:EPS:R
```

где

* F — номер функции;
* A, B — пределы интегрирования;
* EPS — требуемая точность;
* R — точное значение интеграла.

Пример:

```bash
./integral -I 2:0:1:0.000001:-8.25
```

Вывод:

```text
-8.2500000000
0.0000000000
0.0000000000
```
