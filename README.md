## Структура проекта

### functions.asm

Ассемблерная реализация функций:

* f1(x)
* f2(x)
* f3(x)

а также их производных:

* df1(x)
* df2(x)
* df3(x)

Производные используются в реализации метода Ньютона.

Соглашение вызова: cdecl.

---

### functions.c

Вспомогательные функции:

* f12(x) = f1(x) − f2(x)
* f13(x) = f1(x) − f3(x)

Используются при вычислении площади фигуры.

---

### functions.h

Объявления всех функций проекта:

* исходных функций;
* производных;
* методов поиска корней;
* метода вычисления интегралов.

---

### root_hord.c

Функция

```c
double root_hord(afunc *f,
                 afunc *g,
                 double a,
                 double b,
                 double eps);
```

Вычисляет точку пересечения двух функций методом хорд (секущих).

---

### root_newton.c

Функция

```c
double root_newton(afunc *f,
                   afunc *g,
                   afunc *df,
                   afunc *dg,
                   double a,
                   double b,
                   double eps);
```

Вычисляет точку пересечения двух функций методом Ньютона.

---

### integral.c

Функция

```c
double integral(afunc *f,
                double a,
                double b,
                double eps);
```

Вычисляет определённый интеграл по формуле Симпсона.

Точность контролируется правилом Рунге.

---

### main_hord.c

Основная программа для варианта с методом хорд.

Поддерживает:

* вычисление площади фигуры;
* вывод точек пересечения;
* вывод количества итераций;
* тестирование функций root и integral.

---

### main_newton.c

Основная программа для варианта с методом Ньютона.

Поддерживает:

* вычисление площади фигуры;
* вывод точек пересечения;
* вывод количества итераций;

## Использование

### Вычисление площади

Для метода хорд:

```bash
./integral
```

Для метода Ньютона:

```bash
./integral_newton
```

Пример вывода:

```text
Area = 5.0877666262
```

---

### Вывод точек пересечения

Для метода хорд:

```bash
./integral -r
```

Для метода Ньютона:

```bash
./integral_newton -r
```

Пример вывода:

```text
A = 5.0983867100
D = 1.3770147368
C = 4.2685440383
```

---

### Вывод числа итераций

Для метода хорд:

```bash
./integral -i
```

Для метода Ньютона:

```bash
./integral_newton -i
```

Пример:

```text
f1-f2: 3
f1-f3: 12
f2-f3: 3
```

Количество итераций зависит от выбранного метода и требуемой точности.

---

### Тестирование root

Формат:

```bash
./integral -R F1:F2:A:B:EPS:R
```

или

```bash
./integral_newton -R F1:F2:A:B:EPS:R
```

где

* F1, F2 — номера функций;
* A, B — границы интервала;
* EPS — требуемая точность;
* R — ожидаемый результат.

Пример:

```bash
./integral -R 1:2:4:6:0.000001:5.09838671
```

Вывод:

```text
5.0983867100
0.0000000000
0.0000000000
```

где:

1. найденный корень;
2. абсолютная ошибка;
3. относительная ошибка.

---

### Тестирование integral

Формат:

```bash
./integral -I F:A:B:EPS:R
```

или

```bash
./integral_newton -I F:A:B:EPS:R
```

где

* F — номер функции;
* A, B — пределы интегрирования;
* EPS — требуемая точность;
* R — точное значение интеграла.

Пример:

```bash
./integral -I 2:0:1:0.000001:-8.25
```

Вывод:

```text
-8.2500000000
0.0000000000
0.0000000000
```

## Дополнительное задание

Реализован второй метод решения нелинейных уравнений — метод касательных (Ньютона).

Для метода Ньютона используются аналитические производные функций:

```math
f_1'(x)= -\frac{1.5}{(x+1)^2}
```

```math
f_2'(x)=2.5
```

```math
f_3'(x)= -\frac{5}{x^2}
```

Производные реализованы на языке NASM в модуле `functions.asm`.

Для сравнения методов предусмотрена сборка двух независимых исполняемых файлов:

* `integral` — метод хорд;
* `integral_newton` — метод Ньютона.
